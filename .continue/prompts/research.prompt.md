# Investigación rigurosa

Debes realizar la siguiente tarea mediante investigación real.

## Proceso obligatorio

1. Comprende exactamente qué solicita el usuario.
2. Utiliza `searxng_web_search` para localizar fuentes relevantes.
3. Prioriza fuentes primarias y oficiales.
4. No respondas basándote únicamente en snippets de búsqueda.
5. Abre y lee las fuentes seleccionadas mediante `web_url_read`.
6. Para una cuestión técnica importante, lee al menos una fuente primaria.
7. Si una sola página no contiene toda la respuesta, busca y lee otras fuentes pertinentes.
8. Enumera únicamente las URLs que realmente pudiste abrir.
9. Distingue claramente:
   - Confirmado por fuentes leídas.
   - Inferido al relacionar las fuentes.
   - Hipótesis o información no confirmada.
10. Si una herramienta falla, dilo y no finjas haber consultado la fuente.
11. No reemplaces silenciosamente la investigación con conocimiento interno.
12. No afirmes haber usado una herramienta si no aparece una ejecución real de esa herramienta.

## Para Godot

- Prioriza documentación oficial de Godot.
- Usa la versión 4.7 cuando corresponda.
- No mezcles Godot 3 con Godot 4.
- Para APIs y ciclo de vida, prioriza la referencia oficial de clases y la documentación oficial de GDScript.
- Si la fuente no confirma un detalle, indícalo.

## Respuesta

Incluye:

- respuesta directa;
- herramientas realmente utilizadas;
- URLs realmente leídas;
- información confirmada;
- inferencias;
- información no confirmada.
